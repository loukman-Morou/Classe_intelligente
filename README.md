# Smart Class

Plateforme intelligente destinée aux classes permettant aux étudiants
d'apprendre à partir des cours de leur classe et aux professeurs
d'identifier anonymement les difficultés pédagogiques.

## Concept

Responsable
    ↓
Classe
    ↓
Cours
    ↓
Étudiants
    ↓
IA
    ↓
Analyse pédagogique
    ↓
Professeur

## Architecture

- Flutter
- NestJS
- PostgreSQL
- pgvector
- Redis
- BullMQ
- Object Storage
- OCR
- RAG
- LLM
